## Distinguish four kinds of values

- **Runtime defaults** are actual fallbacks implemented in code. Backend and judge YAML generally do not fill missing fields from an example.
- **Example values** come from repository examples or upstream bootstrap demos, which may point to another site.
- **Installer-generated values** are calculated at first installation from paths, ports, CPUs, and RAM. Existing private configuration is normally retained on retries.
- **Effective values** come from actual instance files plus systemd units and drop-ins. AI settings are additionally stored per user.

Examples use `/opt/LibreOJ`. For a custom `--prefix`, substitute the actual instance path everywhere. Changing one environment variable does not relocate an installation.

## Applying changes

| Changed setting | Activation |
| --- | --- |
| `config/backend.yaml` | Validate the complete YAML and restart `libreoj-backend`; refresh the browser to reload public preferences |
| `config/judge.yaml` | Drain work and follow the judge maintenance procedure; slot, CPU, and directory changes also require generating and installing matching systemd units |
| systemd environment/resource limits/drop-ins | Run `systemctl daemon-reload`, then restart the affected service; reload alone does not restart its process |
| `config/nginx.conf` | Test with `nginx -t`, then reload; keep domains and storage signing URLs consistent |
| MariaDB/Redis/MinIO | Restart the corresponding service in a maintenance window and verify backend access and persistence |
| Frontend build settings or static assets | Rebuild/publish to the directory actually served by Nginx and refresh the browser |
| AI model/search settings and permissions | Save through the UI; jobs also recheck permissions while running, as described in the AI guide |

Installer flags describe initial installation. Re-running a completed installation with `--judge-slots`, `--port`, or `--public-url` is not a reconfiguration interface: installation metadata may reject different inputs and generators retain existing YAML. Do not delete installation state, `secrets.json`, the AI master key, or data to bypass this behavior.

## Common changes

For more or fewer CPUs/RAM, use [Judge resizing](Judge-Configuration.md). For names, ports, domains, mail, upload limits, and service memory, see [Operations](Operations-Configuration.md). For models and Tavily/MCP, see [AI](AI.md).

Back up the database, object storage, configuration, and AI key state together. Source code alone cannot restore a site. Keep real secrets out of Wiki pages and GitHub. When a later version adds fields, recheck its schemas and environment-variable consumers.

## Loading and complete field reference

`LIBREOJ_JUDGE_CONFIG_FILE` must name the configuration file; missing it is fatal. Required fields have no class defaults. Table examples come from example YAML, not defaults when omitted; generated installer values may differ. Placeholder key/rootfsId values are not runnable. Optional fields accept omission or null; `sandbox` is required and `cpuAffinity` is optional. Use documented fields rather than relying on rejection of unknown keys.

| Field | Type/validation/example | Purpose, installed value and limits |
| --- | --- | --- |
| `serverUrl` | string; example `http://api.libreoj.test/` | Backend origin without `/api`; connects to namespace `/judge`, path `/api/socket`. Local installation uses `http://127.0.0.1:2002`; remote uses the site HTTPS origin. |
| `downloadEndpointOverride` | optional string/null; example `null` | Replaces download origin while preserving the original path/query; a path in the override is not a prefix. Local setup uses loopback Nginx; remote normally leaves it unset and must reach signed URLs. |
| `key` | base64 string, exactly 40 characters | Base64 representation of a 30-byte key, registered separately per judge, not a user password. Keep root:root `0600`; never put it in command arguments, screenshots or public logs. |
| `dataStore` | string path; example `/root/judge/data` | Disk cache of downloaded test files by UUID; installer uses `<root>/data/judge/testdata`. No total cache-size setting is provided here; monitor disk usage. |
| `binaryCacheStore` | string path; example `/root/judge/cache` | Compiled binary cache; installer uses `<root>/data/judge/cache`. Cleared on startup; never point it at problem data, backups or another shared directory. |
| `binaryCacheMaxSize` | integer bytes; example `536870912` (512 MiB) | Validator requires an integer; operationally must be at least backend `limit.outputSize`, or the judge exits after authorization. Not a program memory limit. Installer retains the example. |
| `taskConsumingThreads` | positive integer; example `2` | Concurrent backend task/submission consumers, not CPU count; each task can contain many testcases. Values above 3 warn. Generated as `min(3,max(1,slots//2))`. |
| `maxConcurrentDownloads` | positive integer; example `10` | Test-file download queue concurrency; values above 20 warn. Generated as `min(4,slots)`; increasing it does not add execution slots. |
| `maxConcurrentTasks` | positive integer; example `3` | Execution queue capacity, effectively the smaller of this and workspace count; shared by compilation, execution and AI validation. Generator requires equality with workspace count; exceeding OS-reported logical CPU count warns. |
| `taskWorkingDirectories` | nonempty string array; example 3 paths | One unique absolute directory per execution slot; duplicate resolved paths are rejected. Installer uses `<root>/data/judge/work/1..N`, separate tmpfs mounts, cleared on startup. Never reuse data/cache directories. A missing tmpfs may only warn; that is not a valid deployment. |
| `rpcTimeout` | positive integer milliseconds; example `20000` | RPC/authorization timeout; expiry restarts the process and cancels in-flight tasks. Generated value is `30000`. |
| `downloadTimeout` | positive integer milliseconds; example `20000` | Per-attempt stream timer starts after receiving the response; not a complete DNS/connection/response-header deadline in current code. Installer retains `20000`. |
| `downloadRetry` | positive integer; example `3` | Total attempts: 3 means first attempt plus up to 2 retries, not 3 extra retries. |
| `aiRunnerSocket` | optional string; example omitted | Local AI UNIX socket; worker is disabled if this or output directory is absent. All-mode path is `<root>/data/judge/ai-runner.sock`, root:backend-group `0660`; remote uses null. Do not expose as public TCP. |
| `aiGeneratedDirectory` | optional string; example omitted | Private local AI output directory, `<root>/data/ai-generated` in all mode; real directory, not symlink, root:backend-group `0750`. Shared locally with backend; null remotely. |
| `aiRunnerGid` | optional integer; example omitted | When AI worker is enabled, separately checked as a positive integer; all mode uses actual `libreoj` GID. Remote writes 0 with null socket, so disabled; do not use 0 for an enabled worker. |
| `sandbox.rootfs` | string path; example `/opt/rootfs-ng` | Sandbox root filesystem; installed at `<root>/runtime/sandbox-rootfs`. Preserve matching recipe, UIDs and mount layout; never recursively chown it. |
| `sandbox.rootfsId` | 64 lowercase hex characters | Required SHA-256 recipe ID; checked exactly against ID file at startup. Mismatch is fatal; example placeholder is not runnable. |
| `sandbox.rootfsIdFile` | optional string; example omitted | Defaults to `<sandbox.rootfs>/etc/libreoj-rootfs-id`; immutable images may use an external ID file via an absolute path. |
| `sandbox.hostname` | optional string/null; example `null` | Sandbox hostname; installer sets `libreoj-judge`. Not the backend connection address. |
| `sandbox.immutable` | optional boolean; example omitted | Absent behaves as false; true uses internal `/tmp/libreoj` paths and avoids creating mount directories inside the image. It does not turn an arbitrary rootfs read-only by itself; use with the matching layout. |
| `sandbox.resourceMode` | optional `default` or `arbiter`; example omitted | Generated as `default`, affecting user programs only. Default uses cgroup CPU accounting; arbiter uses process user CPU time and an additional address-space limit. Compiler/checker/interactor stay default. Changes judging semantics, not a speed toggle. |
| `sandbox.user` | string; example `sandbox` | User resolved inside rootfs to UID/GID; installer uses sandbox. Not the systemd service User; sandbox manager needs its host privileges. |
| `sandbox.environments` | object of environment variables | Example sets `PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin`, `HOME=/sandbox`, `LC_ALL=en_US.UTF-8`. Use string values; merged with task-specific environment. Does not configure host Node thread pool. |
| `cpuAffinity.compiler` | optional integer array; example `[0,1]` | Logical CPU IDs allowed for compilation; installer uses selected judge CPU set. |
| `cpuAffinity.userProgram` | optional integer array; example `[1]` | Logical CPU IDs allowed for user programs; does not pin each slot exclusively to a separate CPU. |
| `cpuAffinity.interactor` | optional integer array; example `[0]` | Logical CPU IDs allowed for interactors; must fit the cgroup allowed CPU set. |
| `cpuAffinity.checker` | optional integer array; example `[0,1]` | Logical CPU IDs allowed for checkers; unset affinity adds no per-kind constraint, but systemd/parent cgroup constraints still apply. |

The complete example mapping keys are `sandbox.environments.PATH`, `sandbox.environments.HOME`, and `sandbox.environments.LC_ALL`. `sandbox.environments.*` is an extensible string mapping, not another fixed field schema; example values appear above.

## Host environment, queues and resource budgets

- `LIBREOJ_JUDGE_CONFIG_FILE`: required path; generated service points to `<root>/config/judge.yaml`.
- `LIBREOJ_JUDGE_LOG_LEVEL`: defaults to `info`; temporarily use `verbose`/`debug` for diagnosis, keeping logs with signed download URLs private.
- `UV_THREADPOOL_SIZE`: set before Node starts, an integer from `2 × effective execution slots + 2` through `1024`. Node's default 4 is sufficient only for 1 slot; 3 slots need at least 8, and 7 need 16. Native sandbox waits occupy libuv workers; interaction can need two child waits per slot, plus two filesystem workers. Generated value is `max(4, slots*2+2)`. Restart judge after changes; setting this inside `sandbox.environments` does not work.
- Generated `NODE_OPTIONS=--max-old-space-size=512` controls Node heap, not contestant memory; `PATH` selects installed Node and host tools.
- `HYHOJ_AI_SAMPLE_INPUTS_DIR`: private host AI sample-input directory, default `/opt/LibreOJ/data/ai-sample-inputs`, generated as `<root>/data/ai-sample-inputs`. Must agree with backend and must not be publicly served.

Ordinary backend consumers use `taskConsumingThreads`. Compilation, testcase execution and local AI validation share `min(maxConcurrentTasks, workspace count)` execution slots. Downloads have a separate `maxConcurrentDownloads` queue. AI runner has a fixed three concurrent generation pipelines and up to eight accepted unfinished requests, including queued work; these are not another three/eight CPU slots and have no YAML tuning keys. Backend AI concurrency is another layer. Raising consumer/AI concurrency alone does not add CPU capacity.

Backend authorization supplies `limit.compilerMessage`, `limit.outputSize`, `limit.dataDisplay`, `limit.dataDisplayForSubmitAnswer`, and `limit.stderrDisplay`; these are not judge.yaml fields. Compiler messages over 1 MiB, data display over 1 KiB and stderr display over 10 KiB warn. Binary cache smaller than outputSize is fatal. Problem/language time and memory limits also come from backend.

Installer sizing uses available logical CPUs from `os.sched_getaffinity(0)`. All mode reserves the first sorted CPU for the site when several exist; remote mode does not. RAM budget subtracts 2048 MiB locally or 1024 MiB remotely, then allows one slot per remaining 512 MiB, capped by available CPUs and 7. Generator floors its memory slot count at 1; the maintenance example below is stricter and refuses a budget unable to fit even one slot. The 3 GiB installation minimum does not imply suitability for high concurrency.

Each slot's 512 MiB tmpfs is a **maximum filesystem size**, not preallocated RAM and not a total process-memory cap. Compilers, programs, page cache, AI data and databases also consume memory. Use fewer slots for large-memory problems, interaction and AI generation; monitor OOM, available memory and judging latency. Parent/service `memory.max`, CPUQuota and cpusets may be smaller than host resources and require separate checks.

`lscpu -e=CPU,CORE,SOCKET,ONLINE` distinguishes logical CPUs from physical cores. SMT siblings share a physical core: eight logical CPUs are not necessarily eight independent cores. CPU IDs need not be contiguous. Four affinity sets, systemd `AllowedCPUs`, and parent cgroup jointly restrict scheduling; the generator writes their union to AllowedCPUs, not one exclusive CPU per slot.

**Eight available logical CPUs and 8 GiB RAM, all mode:** with IDs 0–7, select CPUs 1–7, seven slots, three consumers, four downloads, workspaces 1–7 and thread pool 16. The sizing formula allows this; observe real workload before relying on it. Remote generation is also capped at seven, selecting 0–6 by default. **Seven is an installer/generator support limit, not a judge-core hard limit.** Going beyond seven requires independently designed mounts, CPU/memory/thread-pool settings and validation; bypassing checks does not make it a supported installer configuration.

## Generated systemd service and tmpfs mounts

The table covers every directive emitted by `configure-judge.py` and identifies common accounting/limit settings it does not emit. Static templates can differ from resource-aware generated units; review the generated files and higher-priority service drop-ins.

| Directive | Generated value | Meaning/constraints |
| --- | --- | --- |
| `Unit.Description` | `Judge: slots/consumers; workspace/remote target descriptions` | Descriptive text, not a resource limit. |
| `Unit.After` | `local: libreoj-backend.service; remote: network-online.target` | Startup ordering; remote target also follows network-online.target. |
| `Unit.Requires` | `local service: libreoj-backend.service` | No backend dependency on a remote node; stopping local backend affects its dependent judge. |
| `Unit.Wants` | `remote service: network-online.target; remote target: libreoj-judge.service` | Weak dependencies to activate remote networking/judge; not a multi-node scheduling rule. |
| `Unit.PartOf` | `service and mounts: libreoj.target or libreoj-judge.target` | Different all/remote stop/restart membership. Resize stops judge service, not the whole all target. |
| `Unit.RequiresMountsFor` | `all taskWorkingDirectories` | Service depends on configured workspace mounts; must match YAML. |
| `Unit.Before` | `not explicitly generated` | No explicit Before value; RequiresMountsFor and systemd default dependencies supply ordering. |
| `Service.WorkingDirectory` | `<root>/apps/judge` | Node working directory; dependencies there must remain readable. |
| `Service.Environment` | `NODE_ENV=production; PATH=<node-parent>:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin` | Also generates LIBREOJ_JUDGE_CONFIG_FILE, UV_THREADPOOL_SIZE, NODE_OPTIONS=--max-old-space-size=512, HYHOJ_AI_SAMPLE_INPUTS_DIR; see host environment section. |
| `Service.ExecStart` | `<node> -r @swc-node/register index.mjs` | Judge uses the TypeScript registration entry, not backend dist/main.js. |
| `Service.Delegate` | `cpu memory pids` | Delegates cgroup controllers to native sandbox; do not remove or replace with a sudo prefix. |
| `Service.DelegateSubgroup` | `supervisor` | Requires systemd254+; separates manager from sandbox child cgroups. |
| `Service.OOMPolicy` | `continue` | Does not stop/kill the entire service via OOMPolicy for a sandbox OOM; does not prevent host exhaustion. |
| `Service.AllowedCPUs` | `union of the four cpuAffinity sets` | Logical CPU IDs, constrained by parent cgroup; regenerate and restart. |
| `Service.TasksMax` | `2048` | Host service task/thread limit, not submission or execution-slot count. |
| `Service.Restart` | `on-failure` | Restarts after failure; bad configuration may repeatedly fail, requiring log inspection. |
| `Service.RestartSec` | `3` | Wait three seconds before restarting after failure. |
| `Service.TimeoutStopSec` | `30` | Thirty-second stop timeout is not queue draining and does not guarantee in-flight completion. |
| `Service.UMask` | `0022` | Default mask for ordinary new judge files; private config and AI paths/socket use explicit stricter permissions. |
| `Service.LimitCORE` | `0` | Disables core dumps. Other Limit* settings such as LimitNOFILE are not emitted and inherit host/systemd settings. |
| `Service.StandardOutput` | `journal` | Standard output goes to journal; keep diagnostic logs private. |
| `Service.StandardError` | `journal` | Standard error goes to journal. |
| `Service.User / Service.Group` | `not explicitly generated` | System service therefore uses host root by default; sandbox.user is a different inside-sandbox identity. |
| `Service.CPUAccounting / Service.MemoryAccounting / Service.TasksAccounting` | `not explicitly generated` | Inherit systemd manager/parent-slice settings; do not claim generator sets a value. Inspect effective settings with systemctl show. |
| `Service.MemoryMax / Service.CPUQuota` | `not explicitly generated` | Parent cgroup or drop-in can still limit them; per-problem sandbox limits are configured separately. |
| `Mount.What` | `tmpfs` | One independent tmpfs filesystem per workspace. |
| `Mount.Where` | `each taskWorkingDirectories path` | Unit name comes from systemd-escape --path --suffix=mount; do not guess path escaping. |
| `Mount.Type` | `tmpfs` | Not the disk testdata store; do not mount over rootfs to replace storage. |
| `Mount.Options` | `size=512m,mode=0755,nodev,nosuid` | Size is each tmpfs maximum; mode controls mount-root permissions; nodev/nosuid prevent device-node/setuid behavior. |
| `Install.WantedBy` | `service/mounts: mode target; remote target: multi-user.target` | Enable creates target .wants links; remote target needs boot enablement. Resize retains existing target enablement. |

Inspect effective `CPUAccounting`, `MemoryAccounting`, and `TasksAccounting` read-only; resizing does not require independently changing them.

```bash
sudo systemctl show libreoj-judge.service -p CPUAccounting -p MemoryAccounting -p TasksAccounting -p LimitCORE -p TasksMax
```

## Resize an existing installation

This procedure does not reinstall or create another key. `--judge-slots` is a first-install option stored in installer metadata. Rerunning with a changed value may fail with “metadata differs”; the completed-install branch does not rebuild judge configuration. `configure-judge.py` preserves fields in an existing judge.yaml after checking instance identity; changing only `OJ_JUDGE_SLOTS` will not replace it. **Do not delete YAML/secrets/metadata or edit installer metadata to force resizing.**

Confirm this node already has `libreoj-judge.service`. A `--role web` node has no local judge to resize: deploy a [remote judge](Remote-Judge.md) or plan a complete all-mode deployment. Local all mode retains its AI worker; remote mode handles ordinary judging and uses `libreoj-judge.target`. The example requires standard installer `work/1..N` paths. Review custom mounts, service symlinks and drop-ins separately.

1. Schedule maintenance, prevent new submissions, rejudges, test runs and AI jobs, and wait for queued/running work from **every user** to finish; your own AI list is insufficient. There is no generic judge-drain command in this version. Idle CPUs do not prove an empty queue. Inspect Pending submissions, judge logs and queued/running AI job storage through administrator access. Apply only after draining; if new requests cannot be prevented, remain in plan mode because a race remains.
2. Inspect resource limits and service overrides read-only. These selected properties do not print the full environment/key. Lower target slots when parent quotas are smaller. Existing drop-ins must not override the new CPU/thread-pool configuration.

```bash
lscpu -e=CPU,CORE,SOCKET,ONLINE
free -h
sudo systemctl show libreoj-judge.service -p DropInPaths -p AllowedCPUs -p EffectiveCPUs -p MemoryMax -p CPUQuotaPerSecUSec
```

3. The full block below defaults to a read-only plan: no files written, no services stopped. Change OJ_ROOT for a custom prefix, reduce OJ_RESIZE_SLOTS to shrink, or set OJ_RESIZE_MODE=remote on an independent judge. After draining, rerun the complete block with only OJ_RESIZE_APPLY changed from 0 to 1. Optionally select logical IDs from separate physical cores with OJ_RESIZE_CPUS=1,2,3,4,5,6,7; its length must equal slot count.

Apply first creates a private backup of YAML, installed related units and generated templates, then stops only judge. It preserves key, URL, rootfs and AI settings and changes only capacity fields. Remote generator gets its original URL and a private copy of the existing key, never a new identity. It generates/verifies/installs service and mounts, disables and removes retired mount units, enables new mounts, reloads systemd, verifies sandbox and starts judge. Web/database are not restarted; retained workspaces are not unmounted. Do not run this concurrently from multiple terminals.

```bash
sudo env OJ_ROOT=/opt/LibreOJ OJ_RESIZE_MODE=all OJ_RESIZE_SLOTS=7 OJ_RESIZE_APPLY=0 python3 - <<'PY'
import datetime, json, os, re, shutil, subprocess, sys
from pathlib import Path
import yaml

root = Path(os.environ.get('OJ_ROOT', '/opt/LibreOJ'))
mode = os.environ.get('OJ_RESIZE_MODE', 'all')  # all or remote
slots = int(os.environ.get('OJ_RESIZE_SLOTS', '7'))
apply = os.environ.get('OJ_RESIZE_APPLY', '0') == '1'
if os.geteuid() != 0 or mode not in ('all', 'remote'):
    raise SystemExit('Run with sudo; mode must be all or remote')
if not root.is_absolute() or root == Path('/') or not re.fullmatch(r'/[A-Za-z0-9_./-]+', str(root)):
    raise SystemExit('Use a valid absolute installation prefix')
root = root.resolve()
config = root / 'config/judge.yaml'
if config.is_symlink() or not config.is_file():
    raise SystemExit('judge.yaml must be a regular file')
try:
    c = yaml.safe_load(config.read_text())
except yaml.YAMLError:
    raise SystemExit('Cannot parse judge.yaml (private key withheld)') from None
available = sorted(os.sched_getaffinity(0))
candidates = available if mode == 'remote' or len(available) == 1 else available[1:]
mem = dict(line.split(':', 1) for line in Path('/proc/meminfo').read_text().splitlines())
ram_mib = int(mem['MemTotal'].split()[0]) // 1024
reserve_mib = 1024 if mode == 'remote' else 2048
maximum = min(7, len(candidates), max(0, (ram_mib - reserve_mib) // 512))
if not 1 <= slots <= maximum:
    raise SystemExit(f'Requested slots exceed CPU/RAM budget; maximum here is {maximum}')
cpus = candidates[:slots]
if os.environ.get('OJ_RESIZE_CPUS'):
    cpus = [int(x) for x in os.environ['OJ_RESIZE_CPUS'].split(',')]
if len(set(cpus)) != slots or len(cpus) != slots or not set(cpus) <= set(candidates):
    raise SystemExit('Choose one distinct allowed logical CPU per slot')
work = root / 'data/judge/work'
old_dirs = [Path(x) for x in c['taskWorkingDirectories']]
if old_dirs != [work / str(i) for i in range(1, len(old_dirs) + 1)]:
    raise SystemExit('This example requires standard work/1..N paths; review custom layouts separately')
if any(p.is_symlink() for p in [root/'config', work, *old_dirs]):
    raise SystemExit('Configuration/work directories must not be symlinks')
new_dirs = [work / str(i) for i in range(1, slots + 1)]
if any(p.is_symlink() for p in new_dirs):
    raise SystemExit('New workspace must not be a symlink')
def run(*args):
    return subprocess.run(list(args), check=True)
def mount_name(p):
    return subprocess.check_output(['systemd-escape', '--path', '--suffix=mount', str(p)], text=True).strip()
old_mounts, new_mounts = [mount_name(p) for p in old_dirs], [mount_name(p) for p in new_dirs]
target = 'libreoj-judge.target' if mode == 'remote' else 'libreoj.target'
service = 'libreoj-judge.service'
extra = ['libreoj-judge.target'] if mode == 'remote' else []
installed = Path('/etc/systemd/system')
source_units = root / 'deploy/systemd'
print(f'Plan: {len(old_dirs)} -> {slots} slots; CPUs={cpus}; RAM={ram_mib}MiB; reserve={reserve_mib}MiB')
print(f'UV_THREADPOOL_SIZE={slots*2+2}; target={target}; key and other configuration retained')
if not apply:
    print('Read-only plan. Drain all submissions/AI jobs, then rerun with OJ_RESIZE_APPLY=1.')
    sys.exit(0)
# Nothing below runs in plan mode. Keep the backup private; it contains a judge key.
backup = Path('/var/backups/libreoj-judge') / datetime.datetime.now(datetime.timezone.utc).strftime('%Y%m%dT%H%M%S%fZ')
backup.mkdir(parents=True, mode=0o700)
backup.chmod(0o700)
shutil.copy2(config, backup/'judge.yaml')
(backup/'judge.yaml').chmod(0o600)
(backup/'installed').mkdir(mode=0o700)
shutil.copytree(source_units, backup/'generated')
names = [service, *extra, *old_mounts]
for name in set(names + new_mounts):
    if (installed/name).is_symlink():
        raise SystemExit('Custom symlink unit requires manual review: ' + name)
for name in names:
    p = installed/name
    if p.is_symlink():
        raise SystemExit('Custom symlink unit requires manual review: ' + name)
    if p.exists(): shutil.copy2(p, backup/'installed'/name)
enabled = {name: subprocess.run(['systemctl', 'is-enabled', '--quiet', name]).returncode == 0 for name in old_mounts}
manifest = {'root':str(root), 'mode':mode, 'old_mounts':old_mounts, 'new_mounts':new_mounts,
            'extra':extra, 'enabled':enabled}
(backup/'manifest.json').write_text(json.dumps(manifest, indent=2)+'\n')
print('PRIVATE BACKUP:', backup, flush=True)
run('systemctl', 'stop', service)
try:
    # Only capacity-related YAML values change; key/rootfs/server/AI settings are untouched.
    c.update(maxConcurrentTasks=slots, taskWorkingDirectories=list(map(str, new_dirs)),
             taskConsumingThreads=min(3, max(1, slots//2)), maxConcurrentDownloads=min(4, slots))
    c['cpuAffinity'] = {name:cpus for name in ('compiler', 'userProgram', 'interactor', 'checker')}
    temporary = config.with_name('judge.yaml.resize-new')
    fd = os.open(temporary, os.O_WRONLY|os.O_CREAT|os.O_EXCL|os.O_NOFOLLOW, 0o600)
    with os.fdopen(fd, 'w') as f: yaml.safe_dump(c, f, sort_keys=False)
    os.replace(temporary, config)
    env = dict(os.environ, HYHOJ_ROOT=str(root), NODE_BINARY=str(root/'runtime/node/bin/node'),
               OJ_JUDGE_REMOTE='1' if mode == 'remote' else '0', OJ_JUDGE_SLOTS=str(slots))
    if mode == 'remote':
        # A private copy of the existing key supplies the generator; no key in argv/logs.
        key_file = backup/'remote.key'
        key_file.write_text(c['key']+'\n'); key_file.chmod(0o600)
        env.update(OJ_JUDGE_SERVER=c['serverUrl'], OJ_JUDGE_KEY_FILE=str(key_file))
    subprocess.run(['python3', str(root/'deploy/configure-judge.py')], env=env, check=True)
    new_names = [service, *extra, *new_mounts]
    run('systemd-analyze', 'verify', *[str(source_units/name) for name in new_names])
    for name in sorted(set(old_mounts)-set(new_mounts)):
        run('systemctl', 'disable', '--now', name)
        (installed/name).unlink(missing_ok=True)
    for name in new_names:
        shutil.copy2(source_units/name, installed/name)
        (installed/name).chmod(0o644)
    run('systemctl', 'daemon-reload')
    for name in new_mounts: run('systemctl', 'enable', '--now', name)
    # No web/database restart. Verify the sandbox before restarting this judge.
    run('systemd-run', '--unit=libreoj-resize-check', '--wait', '--pipe', '--collect',
        '--property=Delegate=cpu memory pids', '--property=DelegateSubgroup=supervisor',
        '--property=LimitCORE=0', '--property=RuntimeMaxSec=120', '--property=TimeoutStopSec=15',
        '--property=WorkingDirectory='+str(root/'apps/judge'),
        str(root/'runtime/node/bin/node'), str(root/'deploy/sandbox/verify-installed.mjs'), '--root', str(root))
    run('systemctl', 'start', service)
    run('systemctl', 'is-active', '--quiet', service)
    print('Judge started. Verify online status and submissions; retain PRIVATE BACKUP:', backup)
except Exception:
    subprocess.run(['systemctl', 'stop', service], check=False)
    print('Resize failed; judge left stopped. Use the rollback block with PRIVATE BACKUP:', backup, file=sys.stderr)
    raise SystemExit(1) from None
PY
```

4. Retain the printed backup privately: it contains a key and must not enter public reports. On failure the block attempts to leave judge stopped; do not continue, use rollback below. After forced termination or host reboot, stop judge and restore the saved state first. On success inspect:

```bash
sudo systemctl status libreoj-judge.service --no-pager
sudo systemctl show libreoj-judge.service -p AllowedCPUs -p EffectiveCPUs
sudo findmnt -t tmpfs
```

## Roll back this private backup

Replace the path with the directory printed by resize. This stops judge, disables added mounts, restores original YAML and saved service/mount/generated templates, restores previous mount enablement and starts the old configuration. It does not change installer metadata or delete problem data, cache roots or physical workspace directories. Repeat online/submission verification afterward.

```bash
sudo env OJ_RESIZE_BACKUP=/var/backups/libreoj-judge/REPLACE_WITH_PRINTED_DIRECTORY python3 - <<'PY'
import json, os, shutil, subprocess
from pathlib import Path
backup = Path(os.environ['OJ_RESIZE_BACKUP']).resolve()
if os.geteuid() != 0 or not backup.is_relative_to('/var/backups/libreoj-judge'):
    raise SystemExit('Use sudo and the exact private backup directory printed by resize')
m = json.loads((backup/'manifest.json').read_text())
root, installed = Path(m['root']), Path('/etc/systemd/system')
def run(*args): subprocess.run(list(args), check=True)
run('systemctl', 'stop', 'libreoj-judge.service')
for name in sorted(set(m['new_mounts'])-set(m['old_mounts'])):
    # A failure before installation may mean that this unit does not exist yet.
    if (installed/name).exists():
        run('systemctl', 'disable', '--now', name)
        (installed/name).unlink()
shutil.copy2(backup/'judge.yaml', root/'config/judge.yaml')
(root/'config/judge.yaml').chmod(0o600)
for name in ['libreoj-judge.service', *m['extra'], *m['old_mounts']]:
    saved = backup/'installed'/name
    if saved.exists(): shutil.copy2(saved, installed/name)
# Restore only generator-managed files; do not delete other project/service units.
generated = root/'deploy/systemd'
for p in generated.glob('*.mount'):
    if 'Description=LibreOJ judge workspace\n' in p.read_text(): p.unlink()
for p in (backup/'generated').iterdir():
    if p.is_file() and (p.suffix == '.mount' or p.name in ['libreoj-judge.service', *m['extra']]):
        shutil.copy2(p, generated/p.name)
run('systemctl', 'daemon-reload')
for name in m['old_mounts']:
    run('systemctl', 'enable' if m['enabled'][name] else 'disable', name)
    run('systemctl', 'start', name)
run('systemctl', 'start', 'libreoj-judge.service')
run('systemctl', 'is-active', '--quiet', 'libreoj-judge.service')
print('Old judge configuration and units restored; verify online status and submissions.')
PY
```

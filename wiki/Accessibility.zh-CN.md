# 键盘与读屏软件

简体中文 | [English](Accessibility.md) | [Wiki 首页](Home.md)

LLMOJ 的页面只用键盘也能操作，页面上的变化也会告诉读屏软件。本页列出可用的按键，以及你会看到或听到什么。

## 浏览页面

- **跳到主要内容：** 在页面上第一次按 Tab 会显示这个链接。按 Enter 跳过菜单，直接到页面内容。
- **打开其他页面：** 焦点移到新页面的内容上，与整页刷新后一样，读屏软件会读出页面标题。
- **带选项的菜单：** 包括页面底部的语言菜单，以及 **⋯** 和 **+** 菜单。用 Tab 移到菜单上，然后：
  - 按 **↓** 和 **↑** 在选项间移动；
  - 按 **Enter** 或 **空格** 选择；
  - 按 **Escape** 关闭菜单。
- **账户菜单**（页面顶部你的用户名）在你用 Tab 经过其中的选项时展开。
- **窄屏幕：** **☰** 按钮打开网站菜单，焦点移入菜单。按 Escape 关闭菜单并回到该按钮。
- **小图标按钮**（移除筛选条件、下载、删除、重命名）可以用 Tab 移到，按 Enter 或空格操作。读屏软件会读出它们的名称。

## 登录

- 登录页打开时，光标在用户名框中。触屏设备上不会这样，因为那样会弹出键盘挡住页面。
- 按 Tab 从用户名到密码，按 Enter 登录。**忘记密码** 在密码框之后。
- 用户名或密码错误时，读屏软件会读出错误，错误也与对应的输入框关联。
- 在注册页和重置密码页，Tab 也能移到 **发送验证码**。

## 提交代码

1. 在题目页，用 Tab 移到右侧菜单中的 **提交**，按 Enter。焦点进入代码编辑器。
2. 在代码编辑器中按 Tab 会缩进。要离开编辑器，请按 **Ctrl+M**（Mac 上为 **⌃⇧M**）：此后按 Tab 会移到语言选择和 **提交** 按钮。再按一次即恢复用 Tab 缩进。编辑器底部的提示会说明当前是哪种方式。
3. **返回题面** 回到题目，焦点回到 **提交** 上。

## 实时更新

提交正在评测时，它的页面和评测列表会实时更新：

- **连接中断：** 页面显示 **实时更新已中断，正在重新连接……**，并自动重试。
- **多次重试失败：** 提示改为页面内容可能不是最新的，并提供 **刷新页面** 按钮。
- **连接恢复：** 提示消失，读屏软件会听到“实时更新已恢复”。
- **页面打开时评测完成：** 读屏软件会读出结果，例如“评测完成：Accepted，得分 100。”
- **右上角的通知** 也会被读出，错误会立即读出。

## 手机与缩放

所有页面都可以双指缩放。在手机上，输入框使用 16 像素的文字，这样 iPhone 不会在点按输入框时自动放大。登录、题库、题目页和提交记录在 320 到 768 像素宽的屏幕上都不需要横向滚动。

## 已知限制

- **对比度：** Semantic UI 的部分颜色略低于 WCAG 对小号文字要求的 4.5:1 对比度，包括链接、蓝色按钮和评测状态的颜色。
- **下拉菜单：** 读屏软件会把它们读作列表框，这是 Semantic UI 的结构决定的。
- **标题：** 部分列表页没有一级标题。页面标题显示在浏览器标签上，打开页面时也会被读出。

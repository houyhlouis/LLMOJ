# 题单与讨论

简体中文 | [English](Study-Lists-and-Discussions.md) | [Wiki 首页](Home.md)

## 题单

**题单**（在顶栏中）是你自己要练习的题目列表。题单是私人的：其他人都不能打开，管理员也不例外。要与团队成员共享练习，请使用团队作业（见[团队](Teams.zh-CN.md)）。

- 每个题单有标题（最多 160 个字符）、Markdown 简介，以及最多 1000 道题目。每道题目可以有一个分节标题（最多 120 个字符）和一条笔记（最多 10000 个字符），且只能出现一次。
- 只能添加你能打开的题目。之后失去某道题目的访问权限时，它仍留在题单中，但显示为不可用。
- 每道题目显示你在比赛之外最近一次通过的提交，与题库相同。
- 可以给题单**加星标**；完成后可以**归档**，使它不出现在默认列表中。搜索按标题查找题单。
- 如果打开题单后，同一个题单在别处（例如另一个标签页）被保存过，保存会被拒绝：请重新加载后再修改一次。

题单需要**创建与管理自己的私人题单**权限，所有登录用户默认都有（见[权限](Permissions.zh-CN.md)）。

## 讨论

讨论有自己的页面，也出现在题目页面上；[题解](Solutions.zh-CN.md)也是讨论，遵循相同的规则。下面提到的权限见[权限](Permissions.zh-CN.md)；`preference.security` 设置见[后端配置](Backend-Configuration.zh-CN.md#preferencesecurity)。

### 谁可以发布

| 要做的事 | 需要 |
| --- | --- |
| 发起讨论 | **发布讨论与题解**（开启 `allowEveryoneCreateDiscussion` 时所有登录用户都可以） |
| 回复 | **回复讨论** |
| 添加表情回应 | **为讨论添加表情** |
| 编辑或删除自己的讨论 | **编辑自己的讨论**、**删除自己的讨论** |
| 编辑自己的回复 | **编辑自己的回复** |
| 编辑或删除他人的讨论 | **编辑所有讨论**、**删除所有讨论**，或**管理讨论**特权 |
| 编辑或删除他人的回复 | **管理所有讨论回复**，或**管理讨论**特权 |

与题目一样，讨论的**权限**设置可以把它共享给用户和用户组，并给予读取或写入权限。

### 公开与隐藏

- 开启 `discussionDefaultPublic`（默认开启）时，新讨论是公开的。设为公开或取消公开需要**管理讨论**特权。
- 开启 `discussionReplyDefaultPublic`（默认开启）时，新回复是公开的。关闭时，新回复只有作者和管理者能看到，直到管理者将其公开。在主站，管理者是管理员和具有**管理讨论**特权的用户；在团队中，是具有团队**讨论管理**权限的成员（见[团队](Teams.zh-CN.md)）。
- 再次隐藏回复的方式相同。隐藏的回复从不对访客显示；在团队讨论中批准回复，也不会公开团队的其他内容。

### 维持秩序

- 垃圾内容请删除，而不是隐藏；需要先审阅的回复再隐藏。
- 管理操作（公开、隐藏、删除）会记入审计日志。
- 要禁止某个用户发言，为其设置**拒绝** **发布讨论与题解**和**回复讨论**；要让其完全看不到讨论，**拒绝** **查看讨论与题解**。

# 团队

简体中文 | [English](Teams.md) | [Wiki 首页](Home.md)

从自己的个人主页点击“我的团队”（`/teams`），创建团队或查看已加入、正在申请的团队。顶部导航栏不显示团队，没有面向全部用户的团队目录，其他人的个人主页也不展示私人团队。输入团主提供的数字“团队编号”，确认团队名称和加入方式后，主动加入或提交申请。入团前仅显示这些确认信息及自己的申请，不开放简介、公告、成员列表和资源。界面沿用 OJ 的主题、Markdown、题目编辑器、讨论和比赛页面。

## 创建、加入与邀请

创建者成为团主。团队有名称、简介、公告和三种加入方式：

| 方式 | 行为 |
| --- | --- |
| 免审核加入 | 知道团队编号的登录用户确认后直接成为成员，团队仍为私人 |
| 申请审核 | 提交申请理由，由成员管理员批准或拒绝 |
| 仅邀请 | 不接受普通加入申请，通过有效邀请码加入 |

审核中的申请人只能查看或撤回自己的申请；知道团队编号不代表能浏览团队内部内容。

成员管理员可以创建共享邀请或指定用户的邀请，设置使用次数和有效期，也可停用邀请。邀请链接为 `/team-invite/<邀请码>`；打开链接不会自动入团，登录后点击“接受邀请”才生效。黑名单用户不能通过邀请码绕过限制。

普通成员可以退出团队。团主必须先转让所有权才能退出；转让对象必须是当前成员。移除或退团后，成员失去团队私有内容的访问权限。

## 成员、分组与权限

“成员”页支持搜索、分组与状态筛选、批量审核、移除、加入或解除黑名单、修改备注和批量分组。团队备注用于作业成绩及导出，主站用户名不受影响。

团主或获得主站“管理全部团队及私人资源”权限的用户分配以下团队权限：

| 权限 | 作用 |
| --- | --- |
| 团队设置 | 修改名称、简介、公告和加入方式 |
| 成员管理 | 审核申请、管理成员、备注、分组与邀请 |
| 题目管理 | 创建、复制、编辑团队题目和管理数据 |
| 比赛管理 | 创建和编辑团队比赛，设置访问范围 |
| 题单与作业 | 创建、编辑、归档和导出作业 |
| 讨论管理 | 管理团队讨论 |
| 文件管理 | 归档或恢复团队文件 |

成员管理员不能自行授予这些权限或转让团主。主站权限管理页另外控制“查看团队”“创建团队”和“管理全部团队及私人资源”；“查看团队”只允许访问自己的团队及通过编号加入，不会公开其他团队。查看、创建默认允许，全局管理默认关闭。全局团队管理可访问私人资源，普通成员和团队管理员仍受本团队范围限制。团队权限仅限本团队资源，不授予站点管理员身份，也不能绕过主站的访问、提交、讨论或参赛封禁。

获授成员管理权限者可以创建和管理分组、批量调整分组。未锁定自主换组时，普通成员可以选择自己的分组。团队内部授权组不会出现在普通用户组管理入口。

## 题库、比赛与讨论

“题库”中可创建空白题目，或复制自己有相应编辑权限的题目。复制保留题面、语言版本、样例、评测配置、测试数据和附件；原题不被修改。通过现有题目编辑与文件页面维护内容，成员通过通常的提交页面评测。

比赛支持 NOI / OI、IOI、ICPC、严格 IOI，并有内部、公开和邀请三种访问范围。内部比赛仅对成员开放；公开比赛遵守主站比赛权限；邀请比赛可指定用户，也可共享 `/contest-invite/<邀请码>` 链接。接受比赛邀请只获得该比赛访问权限，不会自动加入团队。比赛题目、代码、记录和榜单仍遵守比赛自己的时间、赛制和权限规则。[Hack](Hacks.zh-CN.md) 遵守比赛设置；[自测](Self-Evaluation.zh-CN.md) 仅作为 NOI / OI 比赛的可选功能，默认关闭。

团队讨论复用主站讨论和回复功能；创建、列表和直接链接都检查团队成员身份。将讨论设为公开、知道记录链接或曾经是作者，都不会绕过团队私有边界。题解仍是一种讨论，具体见 [题解](Solutions.zh-CN.md)。

题目、比赛、讨论、作业可以归档和恢复。归档后不再对普通成员开放；管理员可在“显示已归档”中恢复。团队整体归档保留全部数据，团主或获得全局团队管理授权者可以恢复。

## 题单与作业

建立有序题目列表，为每题填写分节和备注；不设置截止时间时可作为团队题单。作业可指定成员、指定分组，或面向全体成员。成员完成情况、各题最佳得分、总分和 CSV 导出从提交记录计算。

设置截止时间的作业只统计截止时间及以前的普通提交；比赛中的提交不计入。Fake 和 Hacked 记录计零分，不贡献通过状态。成员管理员不会因能查看作业成绩而自动获得他人的代码读取权限。CSV 包含备注，并对可能触发电子表格公式的内容进行转义。

## 团队文件

成员可以上传和下载团队文件；文件管理员可以归档和恢复文件。每个团队的**总空间为 10 GiB，不设单文件大小上限**；一个文件可以使用全部剩余空间。归档保留文件，也保留其空间占用。

大文件会自动按 32 MiB 分块上传，再由存储服务器合并，不需要把整个文件读入应用内存，也不改变现有代理和其他类型上传的限制。服务器在开始上传时预留空间，在获取每块上传地址和完成上传时重新检查权限，并核对实际存储大小。并发上传、伪造文件大小均不能突破总配额。失败或取消会释放预留空间；中断的上传会在 24 小时后过期，未使用的分块由清理流程回收。已有团队通过标准升级流程统一更新为 10 GiB 配额。

下载时重新检查成员身份；已经签发的下载地址最多继续有效 60 秒。成员退出后不能再申请新下载地址。

本功能提供 LLMOJ 本机团队工作流，不包含洛谷的付费套餐、培训服务或外站 RemoteJudge 代理。已有服务器安装本功能需按 [社区功能升级](Community-Upgrade.zh-CN.md) 迁移数据库。

# 团队

简体中文 | [English](Teams.md) | [Wiki 首页](Home.md)

团队是私人的。在自己的个人主页点击“我的团队”（`/teams`），可以创建团队，或查看已加入的团队和自己的申请。团队不会出现在顶部导航栏、公开列表或其他用户的个人主页中。要加入团队，输入团主提供的“团队编号”，确认团队名称和加入方式后加入或提交申请。成为成员之前，只能看到这些信息和自己的申请，看不到团队的简介、公告、成员和资源。

## 加入与邀请

创建团队的人成为团主。团队有名称、简介、公告，以及以下三种加入方式之一：

| 加入方式 | 说明 |
| --- | --- |
| 免审核加入 | 知道团队编号的登录用户确认后直接加入；团队仍是私人的 |
| 申请审核 | 申请人填写理由，由成员管理员批准或拒绝 |
| 仅邀请 | 不接受申请，只能凭有效邀请加入 |

申请审核期间，申请人只能查看或撤回自己的申请。知道团队编号并不能看到团队的私有内容。

成员管理员可以创建面向所有人或指定用户的邀请，设置使用次数和有效期，也可以停用邀请。打开邀请链接（`/team-invite/<邀请码>`）不会自动入团：需要登录后点击“接受邀请”。黑名单中的用户不能通过邀请重新加入。

成员可以退出团队；团主需要先把团队转让给其他成员才能退出。被移除或已退出的成员不能再访问团队的私有内容。

## 成员、分组与权限

“成员”页支持搜索、按分组和状态筛选、批量审核和移除、加入黑名单、备注和批量调整分组。团队备注会显示在作业成绩和导出文件中，不会改变用户名。

团主或拥有主站“管理全部团队及私人资源”权限的用户可以授予以下团队权限：

| 权限 | 允许 |
| --- | --- |
| 团队设置 | 修改名称、简介、公告和加入方式 |
| 成员管理 | 审核申请、移除成员，管理备注、分组和邀请 |
| 题目管理 | 创建、复制和编辑团队题目及其数据 |
| 比赛管理 | 创建和编辑团队比赛，设置谁能参加 |
| 题单与作业 | 创建、编辑、归档和导出作业 |
| 讨论管理 | 管理团队讨论 |
| 文件管理 | 归档和恢复团队文件 |

成员管理员不能给自己授权，也不能转让团队。

主站的“权限管理”页中，“查看团队”“创建团队”和“管理全部团队及私人资源”是三项独立的权限。“查看团队”允许使用自己的团队并通过编号加入团队，不会显示其他团队。查看和创建默认允许；管理全部团队默认关闭，开启后可以访问所有团队的私有资源。团队权限只在本团队内有效：不会让人成为站点管理员，也不能解除主站对访问、提交、讨论或参赛的封禁。

成员管理员可以创建、重命名和归档分组，并调整成员所在的分组。如果没有锁定分组，成员可以自己选择分组。

## 题目、比赛与讨论

在团队的“题库”中可以新建空白题目，或复制一道自己能编辑的题目。复制会包括所有语言的题面、样例、评测设置、测试数据和附件，原题不受影响。团队题目使用通常的题目和文件编辑器编辑，成员在通常的题目页面提交。

团队比赛可以使用 NOI / OI、IOI、ICPC 或严格 IOI 赛制，并可设为内部、公开或邀请：
- **内部**：仅限成员。
- **公开**：遵循主站的比赛权限。
- **邀请**：指定用户，或任何持有共享 `/contest-invite/<邀请码>` 链接的人。接受比赛邀请只能访问该比赛，不会加入团队。

比赛自身关于时间、计分以及代码、提交和榜单的规则仍然有效。[Hack](Hacks.zh-CN.md) 遵循比赛设置；[自测](Self-Evaluation.zh-CN.md) 是 NOI / OI 比赛的可选功能，默认关闭。

团队讨论与主站讨论用法相同，所有列表和链接都会检查团队成员身份：把讨论设为公开、曾经是作者或知道链接，都不能让非成员看到它。[题解](Solutions.zh-CN.md) 也是一种讨论。

题目、比赛、讨论和作业都可以归档和恢复。归档后普通成员看不到；管理员可以在“显示已归档”中恢复。整个团队也可以连同全部内容一起归档，由团主或拥有全站团队管理权限的用户恢复。

## 题单与作业

建立有序的题目列表，可以分节，并为每道题写备注。没有截止时间的是题单，有截止时间的是作业。可以布置给指定成员、指定分组或全体成员。成绩页显示每位成员每道题的最高分和总分，并可导出为 CSV。

成绩遵循全站权限，与提交记录列表相同：没有查看提交记录的权限时，作业不显示成绩，导出文件中也没有。你无法查看的题目显示为不可用，不显示标题和成绩，也不计入总分。团队的题目、比赛和讨论列表中，你无法打开的项目显示**不可用**而不显示标题：加入团队永远不会解除全站的禁止设置。

作业只统计截止时间前的普通提交，比赛中的提交不计入。Fake 和 Hacked 提交记 0 分，也不算通过。能查看作业成绩并不能查看其他成员的代码。导出文件包含团队备注，可能被电子表格当作公式的内容会被转义。

## 团队文件

成员可以上传和下载团队文件；文件管理员可以归档和恢复文件。每个团队**共有 10 GiB 空间，不限制单个文件大小**，因此一个文件可以用完全部剩余空间。归档的文件仍然保留，也继续占用空间。

大文件会自动分成 32 MiB 的块上传，由存储服务器合并，因此其他上传限制保持不变。上传开始前会预留空间，每一块和上传结束时都会重新检查权限，并核对实际存储的大小，所以同时上传或伪造文件大小都不能突破空间限制。上传失败或取消会释放预留的空间；中断的上传会在 24 小时后过期，其分块会被清理。

完成上传时，合并大文件不会阻塞团队的其他操作。先检查上传并保留其空间；然后在不锁定团队的情况下，把各块合并成文件自己的对象，任何上传链接都无法修改它；最后再次检查成员身份、团队和上传，才添加文件。其间被移出团队的成员或已取消的上传不会得到文件，合并出的副本会被删除。

每次下载都会检查成员身份。已经发出的下载链接在成员退出后最多还能使用 60 秒，但退出后不能再获取新链接。

在团队功能出现之前安装的服务器，需要按[功能升级](Community-Upgrade.zh-CN.md)中的说明修改数据库。
